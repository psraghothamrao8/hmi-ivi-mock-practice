Requirements (the "expected" behaviour)
IDRequirement
R1Cluster speed = signal speed exactly.
R2Gear display shows P, R, N, D exactly as the gear signal.
R3Seatbelt warning ON when belt is not fastened and speed > 10. It turns OFF as soon as belt is fastened.
R4Low fuel warning when fuel < 15 %.
R5Door-open warning shows whenever a door is open and ignition is ON, also while driving.
R6Left lever → left arrow blinks. Right lever → right arrow blinks.
R7Reverse gear → rear camera opens every time. Leaving reverse closes it.
R8Ignition OFF → both cluster and centre screen switch off.
R9At ignition ON all cluster lamps light for about 1.5 s (bulb check). This is normal.
R10Clock uses 12-hour format with AM/PM (e.g. 3:30 PM).
R11Volume range 0–30. Display shows the real volume. Mute silences; un-mute restores the earlier volume.
R12Media: next on the last track goes to track 1; previous on track 1 goes to the last. Time format m:ss (seconds 00–59).
R13Incoming call pauses the media.
R14Bluetooth OFF → status "Not connected", phone dial disabled.
R15Call button is disabled if the number is empty.
R16Navigation: empty destination → message "Please enter a destination". ETA = current time + trip time.
R17Navigation text entry is locked when speed > 5 km/h ("Not available while driving").
R18Any app opens within 1 second.
R19Climate: 16–28 °C. Switching to °F converts the value (22 °C = 72 °F).
R20Night theme: text must be clearly readable.
R21German language: ALL labels translated and fully visible.
