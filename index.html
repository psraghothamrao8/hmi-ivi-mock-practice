What is this job, in one minute?

A modern car has a screen in the middle (music, phone, maps, AC) and a screen behind the steering wheel (speed, fuel, warning lights).

  • IVI = In-Vehicle Infotainment = the middle screen (info + entertainment).
  • HMI = Human Machine Interface = anything the person sees/touches to talk to the car: both screens, buttons, warning lights.
  • Tester's job = check that every button, text, icon and warning behaves exactly as the requirement says, and if not, write a clear defect (bug) report with steps, logs and proof.

The JD also says: run ready-made automation tests, read the failures, and report them. You don't have to write the automation – you run it and explain why it failed.
